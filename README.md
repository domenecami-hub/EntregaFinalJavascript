ETREGA FINAL – JAVASCRIPT
Alumna: Paula Camila Domene Maxzud
Nombre del proyecto: Zadira

Zadira es una tienda online dedicada a la comercialización de marroquineria como: carteras, billeteras, accesorios e indumentaria. Para este proyecto decidí desarrollar un e-commerce que simule el proceso de compra, desde la visualización de los productos, como la gestión del carrito, el cálculo del importe total y la confirmación de la compra.

Durante el desarrollo intenté aplicar los conocimientos adquiridos a lo largo del curso y poner en práctica las herramientas trabajadas en las pre-entregas. Utilicé HTML, CSS y JavaScript para construir una interfaz interactiva, incorporé un archivo JSON para cargar los productos y empleé fetch, funciones de orden superior y localStorage para gestionar los datos y conservar los cambios realizados por el usuario.

También integré las librerías SweetAlert2 y Toastify para mejorar la interacción y las notificaciones de la aplicación. Organicé los archivos en carpetas para separar los estilos, los scripts, los recursos multimedia y los datos del catálogo.

Estoy contenta con el resultado obtenido y con todo lo aprendido durante el proceso de desarrollo.
